Mensagens do WhatsApp

Armazenamento e segurança

O modo local serve apenas para testar. Antes de cadastrar clientes, execute o SQL de acesso exclusivo e configure a conexão Supabase. As chaves públicas do projeto são permitidas no navegador; nunca utilize a service_role.

Execute uma vez no SQL Editor do seu projeto Supabase. Crie seu usuário no painel de Authentication.

Backup e manutenção
